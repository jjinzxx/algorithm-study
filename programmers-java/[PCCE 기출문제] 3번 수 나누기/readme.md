# [PCCE 기출문제]
<br><br>

### 문제 설명
```
2자리 이상의 정수 number가 주어집니다. 주어진 코드는 이 수를 2자리씩 자른 뒤, 자른 수를 모두 더해서 그 합을 출력하는 코드입니다. 코드가 올바르게 작동하도록 한 줄을 수정해 주세요.
```
<br><br>

### 제한사항
```
10 ≤ number ≤ 2,000,000,000
number의 자릿수는 2의 배수입니다.
```
<br><br>

### 출력 예시
```
입력 #1

4859
출력 #1

107
입력 #2

29
출력 #2

29
```
