# [PCCE 기출문제]
<br><br><br>

### 문제 설명
직각삼각형이 주어졌을 때 빗변의 제곱은 다른 두 변을 각각 제곱한 것의 합과 같습니다.
<br>
피타고라스.jpg
<br>
직각삼각형의 한 변의 길이를 나타내는 정수 a와 빗변의 길이를 나타내는 정수 c가 주어질 때, 다른 한 변의 길이의 제곱, b_square 을 출력하도록 한 줄을 수정해 코드를 완성해 주세요.
<br><br>

### 제한사항
1 ≤ a < c ≤ 100<br><br>

### 출력 예시
입력 #1<br>
3<br>
5<br>
출력 #1<br>
16<br><br>
입력 #2<br>
9<br>
10<br>
출력 #2<br>
19<br><br>
